Report Overview

This report provides data on the gilts currently in issue, including their names, ISIN codes, first issue dates, redemption and dividend dates and the nominal amounts in issue. For index-linked gilts the data also include the inflation uplifted nominal amounts in issue. The Gilts in Issue report only runs for UK Working Days, if a non-working day is entered the report will display the data for the most recent working day.
